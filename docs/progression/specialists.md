# Specialist mastery

Specialist persistence uses semantic roles, not display names.

- Coordinator / Athena: planning, delegation, recovery, and resource efficiency.
- Investigator / Orion: source reconnaissance, Git archaeology, evidence fusion, and root cause.
- Builder / Daedalus: implementation, refactoring, repair, and architecture.
- Verifier / Argus: tests, regression, requirements, and invariants.

XP is contribution-weighted from finalized assignments. Specialists receive zero when they did not participate. Messages and tool calls are not contribution. Titles are presentation only and grant no authority.

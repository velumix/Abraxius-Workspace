# Security

A valid package signature proves package origin/integrity; it does not grant authority. Publisher trust, plugin enablement, and sandboxing also do not grant authority. Effective access is the intersection of declared permissions, user grants, plugin/project/mission policy, platform capability, and Phase 17 decisions.

Sensitive file, network, process, model, and secret operations are brokered through Security and Lattice. Secret values are not plugin settings or IPC fields. Reduced OS isolation is represented honestly and may be rejected by policy.

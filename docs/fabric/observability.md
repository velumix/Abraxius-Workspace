# Observability

Fabric activities propagate W3C trace context and retain mission, assignment, execution, lease, node, and Artifact correlation. Metrics cover active leases, placement latency/failure, RPC latency/errors, transfers, cache hits, lease expiry, stale results, reconnects, and resource snapshots.

Telemetry is bounded and coalesced before the UI. Secret values and private source snippets never belong in baggage.

# Risk model

Risk is derived from the structured operation and magnitude, never a model hint or tool name. Dimensions are read-only, low-risk mutation, mutation, destructive, external side effect, privileged, credential-sensitive, financial, and shell.

`git status` is read-only; `git push` is external; force push is destructive. Direct executable invocation and shell execution are distinct. Large file counts/byte estimates escalate deletion and mutation risk. Risk affects approval but never creates authority.

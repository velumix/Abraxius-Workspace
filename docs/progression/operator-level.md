# Operator level

Operator XP is the repeatable general progression loop. Version 1 uses an inspectable polynomial per-level requirement:

```text
100 + 35 × (level - 1) + 2 × (level - 1)²
```

Early levels arrive quickly and later levels slow gradually without exponential growth. Cycle XP and lifetime XP are stored separately. Prestige may reset cycle XP only; lifetime XP is permanent.

# Fabric integration

Phase 21 publishes compact, timestamped offers: devices, effective capacity, installed exact variants, residency, context capacity, backend, and pressure. Phase 20 selects a node; the worker then repeats local admission because offers can become stale.

Phase 21 never selects a remote node. Raw backend services are not exposed to the LAN, and LocalOnly context remains subject to Phase 17 transfer policy.

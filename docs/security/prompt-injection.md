# Prompt injection and threat model

Repository files, PDFs, web pages, email, issues, comments, memories derived from external content, model output, imported Skills, and plugins are data. Their text has no policy authority.

Covered threats include malicious retrieved instructions, hallucinated dangerous actions, secret exfiltration, path traversal, symlink escape, internal-network/metadata SSRF, shell/argument injection boundaries, scope escalation, stale grants, deep-link abuse, notification action abuse, replayed side effects, and approval fatigue.

The control is structural: content may produce a typed proposal; canonicalization and deterministic authorization run afterward. A README requesting upload of a private key resolves to an out-of-workspace credential resource plus external destination and is denied before transport.

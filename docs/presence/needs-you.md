# Needs You

Needs You is durable human-attention state, stored independently from notification delivery. Reasons include approval, ambiguous choice, inconclusive verification, missing credentials, external permission, conflicting requirements, budget approval, and security decisions.

Items progress through pending, viewed, resolved, dismissed, expired, or cancelled. Dismissing an OS notification does not modify the item. Approve, reject, and snooze use typed commands. Resolution is persisted before dependent runtime coordination is notified; it never grants a capability or bypasses Lattice policy.

# Achievements

Achievements use constrained deterministic criteria: verified outcome, mission thresholds, career thresholds, specialist facts, and AND compositions. There is no model-defined award path or scripting engine.

The initial pack contains 21 milestones, including First Light, Parallel Mind, No Stone Unturned, Measure Twice, Procedural, Zero Frontier, Against the Odds, Old Memory, regression coverage, independent proof, systems thinking, and long-career milestones. Parallel Mind requires meaningful work in addition to branch count. Rewards are restrained visual identity and career milestones, never permissions.

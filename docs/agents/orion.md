# Orion

Orion is the evidence specialist for `SpecialistRole.Investigator`.

The built-in policy is read-only. Orion assignments use project memory and scheduler-backed memory work, and return concise summaries plus evidence references. Multiple Orion instances may run concurrently for source, history, and memory investigations. Findings are hypotheses until supported by evidence; they are not automatically promoted to semantic memory facts.

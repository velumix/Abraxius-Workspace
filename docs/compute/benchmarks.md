# Compute benchmarks

`ComputeBenchmarks` measures memory-estimation, bounded queue admission, and CPU discovery overhead. Runtime telemetry separately records cold load, warm TTFT, prompt throughput, generation throughput, memory reservation, and measured peak usage.

Performance results do not establish model quality. Variant quality, context reliability, tool use, coding, and AXL behavior belong to Phase 19 eval suites pinned to exact variant/backend/device identity.

Provider and hardware benchmarks must report the actual environment; unknown measurements are never converted to zero.

# Prestige

Prestige is an explicit, atomic legacy transition. Version 1 requires Operator Level 100, 100 verified missions, Level 25 in every core specialist, and one Extreme verified mission.

Activation resets only Operator cycle level/XP. It preserves lifetime XP, specialist mastery, Skill trust and mastery, memory, projects, achievements, settings, and career history. Prestige unlocks no authority and never bypasses policy.

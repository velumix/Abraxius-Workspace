# Design Studio UI

The Avalonia surface provides:

- current registered surface selection;
- provider health and Connect Google action;
- bounded candidate gallery with real provider previews when supplied;
- candidate selection, refinement, artifact identity, and implementation;
- compact status text for capture/compile/generation stages.

No design dashboard invents percentages or fake provider activity. If Stitch is
not configured or unavailable, the provider status explains that state while
the rest of Abraxius remains usable.

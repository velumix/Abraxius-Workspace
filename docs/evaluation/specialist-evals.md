# Specialist evaluation

Athena is measured by mission completion, success-contract fulfillment, delegation, critical path, budget, and replans—not plan prose. Orion is measured by evidence precision/recall, source authority, root-cause accuracy, and time to useful evidence. Daedalus is measured by verified implementation, first-pass Argus pass, regression introduction, tests, and mutation scope. Argus is measured by true/false positives and negatives, coverage, and defect severity.

Handoffs retain evidence identities and measure information loss, unnecessary context, and latency. A stronger model or higher mastery does not alter authorization.

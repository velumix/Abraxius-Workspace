# Datasets

`EvalDataset` records stable identity, version, case identities, origin, provenance, classification, and optional license. Changing cases requires a new dataset version. Origins distinguish Synthetic, RealMissionDerived, UserAuthored, Imported, and Generated data.

Generated cases are candidates until fixture and ground-truth validation. Real trajectories may be harvested only when initial state, expected outcome, verification, and privacy policy permit reproducible reuse. LocalOnly and Confidential datasets retain Phase 17 classification during execution and artifact creation.

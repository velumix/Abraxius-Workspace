# Model and routing evaluation

Model suites record actual provider/model/revision, route, cache state, latency, cost precision, structured-output validity, tool compliance, and verified outcome. Stochastic cases use repetitions and seeds where providers support them; unsupported determinism is declared.

Routing policies must run the same cases. FreeFirst, Balanced, and QualityFirst comparisons report verified success, latency, cost, transitions, and frontier escalation independently. Evaluation produces evidence; it does not silently reconfigure Phase 6.

Model judges are supplementary and must pin judge identity, rubric, and prompt version. Deterministic checks and Argus verification remain primary.

# Career

Career aggregates track missions, verified outcomes, failures, cancellations, verification rate, meaningful parallel structure, peak meaningful concurrency, defects caught, Extreme missions, trusted Skill use, mastered Skills, and free/included versus frontier mission routing.

Aggregates update transactionally with rewards and avoid rescanning long histories during page load. Weekly and future Debrief integrations should consume these structured aggregates. Career data is private by default.
